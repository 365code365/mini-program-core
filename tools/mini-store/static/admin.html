    代码包
    点击或拖入小程序文件夹
    选含 app.json 的那一层；会在浏览器里打成 zip 再上传
    说明
    • app.json 可以在 zip 根上，也可以在唯一一层子目录里。
    • 选文件夹时 ID 留空会按文件夹名自动填。
    • .DS_Store、node_modules 会被跳过。
    • 上传后客户端下次打开时按版本号自动更新。
    • 单包上限 128 MB。
