# 组件对齐清单（对照微信官方组件文档，2026-11-06）

对照的是 <https://developers.weixin.qq.com/miniprogram/dev/component/> 的组件索引与各组件页（属性表、事件 detail、Skyline 说明）。
以 Skyline 为准；官方标「仅 WebView」的组件（progress、icon、movable-view、match-media、editor、keyboard-accessory、
navigation-bar、web-view）优先级相应调低。上几轮逐页核过并已做完的（`.agents/tasks/component-gap-2026-11-03/plan.md`
WP-A~F、F2 / F3）不再列，这里只列**还有出入的**与**这一轮改掉的**。

判据一律可判定：期望值 + 怎么验。「宿主」= 只能在 Android / iOS 宿主里做（键盘、系统播放器、地图 SDK 这类）。

## 这一轮改掉的

| 编号 | 项 | 改了什么 | 守着它的用例 |
|---|---|---|---|
| P0-1 | 触点坐标：`pageX/pageY` 与 `clientX/clientY` 是同一个数 | 事件对象分开给（`host::touch::EventPoint`）：`pageY = clientY + scrollTop`。从前触摸事件两个都给视口坐标（页面滚过之后 pageY 少了 scrollTop），tap 两个都给文档坐标（clientY 多了 scrollTop） | `wpc::events::触点的_page_与_client_坐标_页面滚过之后差一个_scrollTop`：滚到 300 后在视口 (100,100) 按下松手，touchstart / tap 都是 pageY 400、clientY 100，tap 的 detail.y 400 |
| P1-1 | scroll-view 的 `binddragstart / binddragging / binddragend` 只在写了 `enhanced` 时发 | Skyline 没有 `enhanced`、官方把拖动事件列在通用属性里：写了就发 | `wpd::scroll_ctx::d2_没写_enhanced_也发_dragstart_dragging_dragend` |
| P2 | `<large-image>`（Skyline 3.10.3）不认，按 view 兜底 | 按 image 画，mode 默认 widthFix（只认 widthFix / heightFix），`bind:load` 的 detail 是原图 `{width, height}` | `wpc::events::large_image_默认_width_fix_load_带原图尺寸`：宽 80 的 8×8 图高 80、detail `8x8` |
| P2 | web-view 的 `binderror` detail 是 `{src, errMsg, errCode}` | 补上官方的 `{url, fullUrl}`（Android `MiniWebViews.kt`、iOS `MiniWebViews.swift`），老字段照留 | 宿主侧，编译通过；真机没点（要一个打不开的域名） |
| — | slider 拖动（`bindchanging`）每一步整帧重画 | 只重画 slider 自己的盒子（`engine_press.rs::damage_dragging_slider`），松手那一帧同样 | `sdk_damage_transform::转圈的唱片_…_拖进度条_仍逐字节一致`（局部 = 整帧，逐字节） |

## 还没做的（按优先级）

### P1：用得到 / 看得见

| 编号 | 项 | 官方 | 现状 | 改法与验法 |
|---|---|---|---|---|
| P1-2 | 文本选择：text 的 `user-select` / `selectable`、rich-text 的 `user-select`、`<selection>`、`select-on-gesture` | 长按选词、手柄、复制菜单；`selectionchange` 带 `{isCollapsed, selectedString, firstNodeId, …}` | 全没有（grep 0） | 引擎侧做命中与选区绘制（复用 `ui/interaction/text_lines.rs`），菜单交宿主、没接走 `wx.setClipboardData`。验：长按第 2 个字点复制，`getClipboardData` 非空；selectionchange 的 firstNodeId === 节点 id |
| P1-3 | 多指触摸 | `touches` 是全部手指；scale-gesture-handler 的 scale / rotation / pointerCount；movable-view 双指缩放 | 单指（`touch.rs` 只放一个点） | 宿主交多点、`TouchTracker` 按 identifier 记。验：两指距离 100 → 200，scale ≈ 2、`touchmove.touches.length === 2` |
| P1-4 | CSS `font-style: italic`（rich-text 的 i / em / cite） | 斜体 | 不认（只有 canvas 的 font 串认） | 文字光栅化加合成斜体（x 方向切变 ≈ 0.2，同浏览器）。验：italic 与 normal 像素不同、包围盒上沿右移；gallery 加一张；H5 对比不回退 |
| P1-5 | 页面里 `<canvas type="webgl">` | `getContext('webgl')` | 返回 null（WebGL 只在小游戏里有） | 复用 game-webgl 那一套；做不到就照实写进限制、派一次 binderror。验：`gl.clear` 之后中心像素是清屏色 |
| P1-6 | video `danmu-btn` | 控制条上的弹幕开关 | 没有 | `video/chrome.rs` 加一个键。验：带弹幕那一秒点了之后弹幕区像素回到无弹幕时 |
| P1-7 | swiper 指示点默认尺寸 | Skyline 表：宽高 8、间距 4、边距 10、圆角 4 | 7 / 6 / 8（与 H5 导出一致） | 产品决定（改了要动 gallery 与 H5 基线）。验：3 页默认指示点直径 8×dpr、圆心距 12×dpr |
| P1-8 | `type="list"/"custom"` 的 scroll-view、list-builder 只渲染在屏节点 | 回收不在屏的项 | 全部建树布局（与 wx:for 同代价） | 先拿真机 list 页数据再定（这一轮 taffy 缓存补丁之后 200 行改一行重排 0.18ms，桌面）。验：1 万项首次渲染 < 现在的 1/5 |
| P1-9 | page-meta 的 `root-font-size` / `page-font-size` / `page-style` / `page-orientation` | 页面级根样式、rem 基准 | 不生效 | 渲染器加页面根样式与 rem 基准。验：`root-font-size="20px"` 时 `width:10rem` 的 view 宽 200 |
| P1-10 | root-portal 包装层的几何、`externalClass` | 子树挂到页面根 | 包装层没高度；externalClass 没有 | 先真机验 absolute / 百分比高的参照物 |
| P1-11 | input / textarea 的 `bind:selectionchange`、`keyboardcomposition*`、`worklet:onkeyboardheightchange` | Skyline 事件 | 没有 | selectionchange 与 worklet 那项引擎能做；composition 要宿主报输入法状态 |
| P1-12 | scroll-view `min-drag-distance` 默认 18 | 18 | 没写时沿用 4px（刻意保手感） | 真机对比 4 与 18 的手感再定 |
| P1-13 | span 里的 navigator 按行内文字排 | Skyline：navigator 视为文本节点 | span 里一有 navigator 就退回普通容器 | inline_flow 把 navigator 当一段带点击区的 run。验：同一行、点「链接」跳页 |
| P1-14 | picker-view-column 上写的 `indicator-style` | Skyline 支持按列设 | 没接（`picker_view_draw.rs`） | 验：只给第二列写 height:50px，第二列选中框 50、第一列默认 |
| P1-15 | `doc/实现组件说明.md` 严重过期 | — | 还写着 cover-view、movable、page-container 没实现，26/39 | 按 registry（37 个标签，含内部 2 个）与 builtin_components 重写 |

### P2：少见，或只有宿主能做

- **video（多为宿主）**：`vslide-gesture(-in-fullscreen)`、`page-gesture`、`auto-pause-if-open-native`、`show-casting-button` 与 casting 事件、
  video 的小窗、`enable-auto-rotation`、`show-screen-lock / snapshot / background-playback-button`、`is-live`、DRM、`referrer-policy`、`preferred-peak-bit-rate`。
- **input / textarea**：`always-embed`（iOS 宿主）、textarea `show-confirm-bar`（宿主键盘工具栏）、`adjust-keyboard-to`、`bind:nicknamereview`、安全键盘加密。
- **button / form**：`form-type="submitToGroup"` 与 `bind:submitToGroup`；`report-submit`（formId 一律空串，模板消息官方已下线）。
- **scroll-view**：`associative-container`、`worklet:adjust-deceleration-velocity`；`refresher-two-level-pinned` / `ballistic` 只读不用。
- **swiper**：`cache-extent`（全部项都画，可接受）、swiper-item `skip-hidden-item-layout`。
- **cover-view** `scroll-top`；**image** `preload`（Skyline 3.15）；**keyboard-accessory**（没实现）；**editor** 只有纯文本（`enable-formats` 等没有）。
- **开放能力**：`open-data-list / item`、`reward` 按 view 兜底；channel-live / channel-video 只有占位。
- **share-element** 跨页飞跃、**open-container** 展开态没做；**force-press-gesture-handler** 永不触发。
- **movable-view** 动画在逻辑层每 16ms setData 改 left / top（每帧重排一次），可改走 animation 通道。
