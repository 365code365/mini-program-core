# tea-app 触控对齐测试报告

**被测对象**：`sample/tea-app`（uni-app 编译产物，35 个页面）
**测试方式**：全部走无头 CLI，与交互窗体**同一条输入链路**（`on_pointer_press/move/release`）——
`--touch`（完整触摸序列）、`--swipe`（按下→逐步移动→抬起）、`--swipe-hold`（停在终点不抬手）、
`--click`（命中/冒泡/导航）、`--drag`（逐帧计时）。诊断开关 `MINI_SCROLL_LOG=1` 打印手势归属与滚动状态。
事件对象的观察通过 `sample/touch-probe`（把所有触摸绑定写全的探针页）与在 tea-app 上劫持
`__dispatchEvent` 两种方式取得。

**结论**：上下滑动、点击、长按、侧滑返回、方向锁定、`catchtouchmove` 锁滚、触摸事件对象
共 25 项与微信语义一致；发现并修掉 1 个真实缺口（`onPageScroll` 宿主从未派发）；
遗留 2 项已知差距（scroll-view 自身的滚动事件、多指手势），文末列出。

## 六、本轮修复

**`onPageScroll` 从未被宿主派发**（A8）。逻辑层一直有派发入口
（`__dispatchPage('onPageScroll', arg)`，甚至有单测），但宿主没有任何调用点 ——
「滚动到一定位置显示回到顶部按钮」「吸顶导航变色」这类写法在引擎里完全不生效。

现在在每帧的滚动收尾处统一判断：位置变化超过 0.5px 就派发一次
（`src/bin/app_window/event_handler.rs::dispatch_page_scroll`）。放在这一处而不是各条输入路径里 ——
拖动、惯性、回弹、滚轮、脚本设位置最终都会经过这一帧检查，不会漏。

代价实测为零：tea-app 首页拖动 60 帧平均 0.38ms（改动前 0.44ms，在噪声内），
sample-app 15 页快照逐字节不变，damage-check 全绿。

## 七、已知差距（未实现，不在本轮范围）

| 项 | 说明 | 影响面 |
|----|------|--------|
| `scroll-view` 自身的滚动事件 | `bindscroll` / `bindscrolltolower` / `bindscrolltoupper` 目前不派发（页面级 `onReachBottom` 是好的）。tea-app 有 2 处 `bindscrolltolower` | 依赖 scroll-view 触底加载更多的列表不会自动翻页 |
| 多指手势 | 没有双指缩放/旋转，`touches` 数组目前最多 1 个点 | 图片查看器类页面 |
| 点击打断惯性 | 逻辑已实现（按下时停住惯性且这一下不算点击），有单测覆盖（`touch::tests::takeover_emits_cancel_once_then_silence` 等）；但无头 CLI 一次只能驱动一个手势，**「甩动后再点」这一组合没有端到端实测**，需真机确认 | 手感细节 |

## 八、回归与复现

```bash
# 单测（触控/手势/侧滑/事件传播共 47 个用例）
cargo test --lib   # 297 通过，含 tests::touch_event_tests::* 16 个
cargo test --bin mini-app-window   # 44 通过，含 touch/gesture/edge_back 三组

# 本报告的每一条都可以这样复跑（示例）
MINI_SCROLL_LOG=1 ./target/release/mini-app-window sample/tea-app --route pages/index/index \
    --settle 0.6 --time 2 --swipe 200,560,200,120,20 --snapshot target/t
./target/release/mini-app-window sample/tea-app --route pages/index/index --settle 0.8 --time 2 \
    --eval "wx.navigateTo({url:'/pages/tea-king/tea-king'})" --swipe 4,420,300,420,18 --snapshot target/t

# 事件流观察（探针页，把所有触摸绑定写全）
./target/release/mini-app-window sample/touch-probe --route pages/p/p --time 2 --touch 180,100,600 --snapshot target/t
```

覆盖触控语义的单测清单：

- 渲染层事件（`src/tests/touch_event_tests.rs`，16 个）：六种绑定前缀解析、非事件属性不误认、dataset 共享、
  capture→bubble 顺序、`capture-catch` 掐断、`catch` 截断、`mut-bind` 互斥、事件类型隔离、
  `target` 取最内层、`has_catch_for` 按事件类型、覆盖层与正常流两套作用域。
- 触摸状态机（`app_window::touch::tests`，6 个）：tap 序列、slop 取消 tap/longpress、
  长按只发一次且仍有 tap、被接管发一次 cancel 后静默、事件对象形状、无按下时的事件被忽略。
- 手势仲裁（`app_window::gesture::tests`，13 个）：抖动不定向、纵向/横向归属、横向容器里纵划滚页面、
  嵌套传递、`catchtouchmove` 阻止、边缘右划优先于横向容器、边缘手势的三个不触发条件。
- 侧滑返回（`app_window::edge_back::tests`，12 个）：触发区、跟手夹紧、比例/速度判定、
  取消回弹、松手后忽略移动、合成（右移/视差/压暗/阴影/无快照/尺寸不符/零位移）。
