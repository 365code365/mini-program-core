# G0.3 / G0.8 探针结论

每项写：结论、证据、对决策的影响。没做完的标「待测」。

## 1. rquickjs 0.12.1 的二进制与守护接口（已核实，读 crate 源码）

| 需求（02 §3.3、§6） | 接口 | 位置（`rquickjs-core-0.12.1/src/`） |
|---|---|---|
| JS 交给 Rust 的二进制借用 | `ArrayBuffer::as_bytes() -> Option<&[u8]>`、`TypedArray::<T>::as_bytes()`、`as_raw()` | `value/array_buffer.rs:242/304`、`value/typed_array.rs:177/182` |
| Rust 交给 JS 的二进制 | `ArrayBuffer::new / new_copy`、`TypedArray::new / new_copy`、`from_source`（零拷贝持有 Rust 缓冲） | `value/array_buffer.rs:91/123/141`、`value/typed_array.rs:97/106` |
| transfer 语义 | `ArrayBuffer::detach()` | `value/array_buffer.rs:259` |
| 看门狗 | `Runtime::set_interrupt_handler(Option<Box<dyn FnMut() -> bool>>)` | `runtime/base.rs:89` |
| 内存上限 | `Runtime::set_memory_limit(usize)`、`set_gc_threshold` | `runtime/base.rs:123/139` |
| GC 与统计 | `Runtime::run_gc()`、`memory_usage()`、`Ctx::run_gc()` | `runtime/base.rs:158/165`、`context/ctx.rs:471` |
| 原生类 | `classes` feature 已在 `Cargo.toml` 开着 | — |

结论：**二进制桥（G1.5）与守护（G1.7）不需要换绑定库，也不需要下到 `qjs` 低层接口**（RK8 关闭）。
调用开销的实测数字（`fillRect` 单次、1MB 往返）放进 G1 的用例 B2 / C12，跑出来后回填这里。
