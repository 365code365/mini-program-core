# 01 现状与差距

这一章只陈述事实：引擎今天有什么、没有什么、证据在哪。设计与计划见 02、04。
行号以 2026-10-26 的 `main` 为准，代码改动后以函数名为准。

## 1. 现状逐项核对

### 1.8 Worker

`wx.createWorker` 是**同一个 QuickJS、同一条线程**里的模块作用域；消息 `JSON.parse(JSON.stringify())` + `setTimeout 0`，
ArrayBuffer 传不过去；同时只允许一个（与官方「最多一个 Worker」的限制一致）（`src/js/prelude/worker-mq.js:9-68`）。

### 1.9 进程级静态状态（多实例 / 多线程的障碍）

`CANVAS_MANAGER`、websocket 与 net_socket 的连接表与事件表（按 JS 自增 id 索引，两个 runtime 会撞号——推断，未实测）、
wxfs 的 fd 表、clipboard、`APP_ROOT`（`src/assets.rs:10`）、data_dir、`text_faces`、图片缓存。
`net::DONE` 已按 owner 隔离；`audio_ctx` 是 thread_local。
Android SDK 用 `EngineTeardown.awaitPrevious()` 保证**一个进程同一时刻只有一个引擎实例**（`EngineCore.kt` 的 `start`）。
