## 一句话结论

引擎现在是「小程序 + Skyline」形态：入口是 `app.json` 与 WXML 页面树，canvas 内容要经页面重画才能上屏，
rAF 是 `setTimeout(16)` 垫片，触摸只认单指且经 WXML 命中，JS↔原生只能传字符串，移动端不出声，没有 WebGL。
小游戏需要的是另一套运行模式：`game.json` + `game.js`、一整屏主画布直接上屏、跟 vsync 的 rAF、全局多点触控、
二进制直通、真音频、真 Worker、WebGL。本计划分 **G0~G10 十一期**：G0~G7 加上 G9 的长稳与发布项全部验收后，可上线纯 2D 小游戏；
G8 完成 WebGL 后，可承载 Cocos / Laya / Three 等主流引擎导出的游戏。粗估总工作量：2D 门槛 120~180 人日；百分百兼容（含 WebGL、WebGPU、wasm、V8/JSC、开放数据域、插件）**240~360 人日**（单人全职，不含等待取证与真机的日历时间，见 04、11 §5）。

## 分期总览

| 期 | 主题 | 交付后能做什么 | 依赖 |
|---|---|---|---|
| G0 | 准备：基线、真机取证、技术探针、纯搬迁 | 有对照基线、有微信真机的参考答案 | — |
| G1 | 运行模式骨架 + 二进制桥 | `game.js` 跑起来、`console` 有输出、ArrayBuffer 能过桥 | G0 |
| G2 | 主画布 + 帧循环 + 上屏 | 2D 动画按 vsync 出帧，CPU/GPU 两个后端，三端宿主 | G1 |
| G3 | 输入 | 多点触控、PC 键鼠、覆盖层优先 | G2 |
| G4 | 资源：图片、字体、文本、二进制 I/O | 正常的 2D 游戏素材管线 | G1、G2 |
| G5 | 音频 | 移动端出声、音效并发、WebAudio 混音图 | G1 |
| G6 | 包、生命周期、方向、Worker | 分包、前后台、横屏游戏、真多线程 | G2 |
| G7 | 系统 UI 与开放能力 | 键盘、用户信息按钮、Toast/Modal、分享/登录/支付/广告（宿主代理） | G3 |
| G8 | WebGL 1 / 2 | 主流 3D/2D 引擎可跑 | G2、G4、决策 D-2 |
| G9 | 引擎适配、开放数据域、性能、生产化 | Cocos / Laya / Three / Phaser / Pixi 兼容，排行榜，长稳、发布 | 全部 |
| G10 | `WXWebAssembly` | Unity / Emscripten 导出的游戏 | G4、G8 |

**2D 小游戏可上线的门槛 = G0~G7 全部验收 + G9 的长稳与发布项**（G8 不在 2D 门槛内）。

## 对齐目标

`10-skyline-target.md` 规定唯一对标对象是 Skyline，那是**小程序**的对标。小游戏的对标对象是
**微信小游戏基础库**（官方文档 + 真机行为）。四个维度照搬 steering 10 的写法，改成小游戏口径：

| 维度 | 达标判据 |
|---|---|
| 渲染结果 | 同一份游戏源码，引擎（CPU 后端）与「Chrome + wx 垫片」逐帧对比，差异 ≤ 实测定死的阈值（05 §4.4）；引擎内 GPU 合成与 CPU 合成**逐字节一致** |
| 交互语义 | `wx.onTouch*` 的事件序列、`identifier` 稳定性、`touches/changedTouches` 内容与微信真机取证一致（05 §3 GT-T） |
| 流畅度 | rAF 默认 **60fps**（官方：默认 60、有效范围 1~60），帧间隔峰值与屏上重复按 05 §5 判，不看平均帧率 |
| API 行为 | 取证探针（`sample-game/g-probe`）在微信真机与引擎上输出的 JSON 逐字段一致（允许差异的字段在白名单里写明理由） |

> 修改 steering 10 把小游戏写进对标对象，属于改用户规则文件，**需要用户同意**（决策 D-0）。在那之前，本目录就是小游戏的对标说明。

## 术语

| 词 | 含义 |
|---|---|
| 主画布 | 第一次 `wx.createCanvas()` 返回的上屏画布；之后再调返回离屏画布 |
| GameEngine | 新增的小游戏运行实例（与 `MiniEngine` 平级，见 02 §2） |
| 游戏层 | 合成器里新增的「一整屏画布」图层形态（02 §5） |
| 二进制桥 | JS↔原生直接传 `ArrayBuffer` / TypedArray，不经 base64（02 §6） |
| 取证 | 在微信真机 / 开发者工具上跑探针，记录参考答案（04 G0.2、05 §2.2） |
| 纯搬迁 | 只移动代码、不改行为，必须用快照 md5 证明等价（steering 20） |
