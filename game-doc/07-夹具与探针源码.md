# 07 夹具与探针源码

05 §2.1 列出的夹具，这里给出**可以直接落盘的源码**与每个夹具的期望。实现时照抄进 `sample-game/<夹具>/`，
之后夹具即为固定输入（改夹具 = 重定基线，提交说明写原因）。

## 0. 共同约定

- 所有夹具读 `wx.getLaunchOptionsSync().query` 取参数，无头用 `--query "n=500&seed=7"` 传。
- 所有夹具用 `sample-game/_lib/t.js` 的小工具输出**机器可读的日志行**，e2e 与真机脚本只认这些前缀：

| 前缀 | 含义 | 例子 |
|---|---|---|
| `T:READY` | 夹具初始化完成 | `T:READY g-square` |
| `T:FRAME <n> <json>` | 第 n 次 rAF 的观测值 | `T:FRAME 3 {"ts":50.0,"x":3}` |
| `T:EV <name> <json>` | 收到的事件（触摸、生命周期、音频…） | `T:EV touchstart {"ids":[0],"n":1}` |
| `T:OK <检查名>` / `T:FAIL <检查名> <原因>` | 夹具自检结果 | `T:FAIL loadFont returned null` |
| `T:DONE <json>` | 夹具跑完的汇总 | `T:DONE {"frames":120}` |
| `PROBE_RESULT:<json>` | 取证探针结果（只有 g-probe） | — |

- 坐标、尺寸一律用**逻辑像素**；画面上的标记用纯色（`#ff0000` 等），便于用像素统计而不是看图来判断。
- 随机数一律用 `_lib/t.js` 的 `T.rand()`（mulberry32，种子取 `query.seed`，默认 1）。无头下 `MINI_RANDOM_SEED` 也会固定 `Math.random`，两者互不依赖。

### 0.1 `sample-game/_lib/t.js`

```js
// 夹具共用的小工具：机器可读日志 + 确定性随机数 + 断言。只依赖 wx 与 console。
var q = (wx.getLaunchOptionsSync && wx.getLaunchOptionsSync().query) || {};
function line(s) { console.log(s); }
function j(o) { try { return JSON.stringify(o); } catch (e) { return '"<unserializable>"'; } }
var seed = (Number(q.seed) || 1) >>> 0;
function rand() { // mulberry32：跨平台位精确，Chrome 参考实现跑出同一串
  seed = (seed + 0x6D2B79F5) >>> 0;
  var t = seed;
  t = Math.imul(t ^ (t >>> 15), t | 1);
  t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
  return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
}
module.exports = {
  q: q,
  ready: function (name) { line('T:READY ' + name); },
  frame: function (n, o) { line('T:FRAME ' + n + ' ' + j(o)); },
  ev: function (name, o) { line('T:EV ' + name + ' ' + j(o)); },
  ok: function (name) { line('T:OK ' + name); },
  fail: function (name, why) { line('T:FAIL ' + name + ' ' + why); },
  check: function (name, cond, why) { cond ? this.ok(name) : this.fail(name, why || 'assert'); return !!cond; },
  done: function (o) { line('T:DONE ' + j(o || {})); },
  rand: rand,
  j: j
};
```

`require('_lib/t.js')` 的解析基准是包根（02 §3.2）。夹具包里有 `_lib` 的软链或拷贝，由 `tools/game-check.sh` 打包前拷贝，**不用软链**，因为 Android 示例 App 解包后软链会失效。

## 2. g-square（GT-K1~K9；A2.2、A2.3；真机节拍）

```js
var T = require('_lib/t.js');
var c = wx.createCanvas();
var ctx = c.getContext('2d');
var fps = Number(T.q.fps) || 0;
if (fps) wx.setPreferredFramesPerSecond(fps);
var info = wx.getSystemInfoSync();
var n = 0, last = -1;
function tick(ts) {
  n++;
  // 方块左边沿 x = n（逻辑像素 × 画布缩放），帧号写进左上角 8 个像素的颜色里（便于像素断言）
  var k = c.width / info.windowWidth;
  ctx.fillStyle = '#000000'; ctx.fillRect(0, 0, c.width, c.height);
  ctx.fillStyle = '#ff0000'; ctx.fillRect(Math.round(n * k), Math.round(100 * k), Math.round(20 * k), Math.round(20 * k));
  ctx.fillStyle = 'rgb(' + (n & 255) + ',' + ((n >> 8) & 255) + ',0)'; ctx.fillRect(0, 0, 2, 2);
  T.frame(n, { ts: ts, dt: last < 0 ? 0 : +(ts - last).toFixed(3), now: +wx.getPerformance().now().toFixed(3) });
  last = ts;
  if (n < (Number(T.q.max) || 1e9)) requestAnimationFrame(tick); else T.done({ frames: n });
}
T.ready('g-square');
requestAnimationFrame(tick);
```

期望：
- `--hz 60 --frames 120`：`T:FRAME` 恰 120 行；`dt` 从第 2 行起全是 `16.667`（±0.001）；第 n 帧截图里红色像素的最小 x = `round(n × k)`。
- `--hz 120 --frames 240`：`T:FRAME` 恰 120 行，`dt` 全是 16.667。
- `--hz 144 --frames 144`：60±1 行；`dt` 只出现 13.889 与 20.833 两种值（2 个与 3 个 144Hz 周期），两者交替。
- `--query fps=30 --hz 60 --frames 60`：恰 30 行，`dt` 全是 33.333。
- 每行 `|ts - now| ≤ 16.7`（K8）。

> 144Hz 下 60fps 的间隔是「2 个周期 13.89ms 与 3 个周期 20.83ms」交替，平均 16.67ms；这是算法的必然结果，不是缺陷（02 §4.2）。

## 3. g-scale（GT-M1、M2；A2.5）

```js
var T = require('_lib/t.js');
var info = wx.getSystemInfoSync();
var c = wx.createCanvas();
var r = Number(T.q.ratio) || 1;            // 0.5 / 1 / dpr / 1.37
c.width = Math.round(info.windowWidth * r); c.height = Math.round(info.windowHeight * r);
var ctx = c.getContext('2d');
ctx.imageSmoothingEnabled = T.q.filter !== 'nearest';
for (var y = 0; y < c.height; y += 8) for (var x = 0; x < c.width; x += 8) {
  ctx.fillStyle = ((x + y) >> 3) & 1 ? '#ffffff' : '#000000'; ctx.fillRect(x, y, 8, 8);
}
ctx.fillStyle = '#00ff00'; ctx.fillRect(0, Math.floor(c.height / 2), c.width, 1); // 1px 横线
ctx.fillStyle = '#0000ff'; ctx.fillRect(Math.floor(c.width / 2), 0, 1, c.height); // 1px 竖线
T.ready('g-scale');
requestAnimationFrame(function () { T.done({ w: c.width, h: c.height }); });
```

运行矩阵：`ratio ∈ {0.5, 1, <dpr>, 1.37}` × `filter ∈ {bilinear, nearest}` = 8 组，每组截第 2 帧。
期望：CPU 帧 md5 = `baseline_game_scale_<ratio>_<filter>`；GPU 与 CPU 0 差异像素。
`ratio=<dpr>` 时（后备缓冲 = 输出像素）必须走 1:1 快路：`MINI_GAME_LOG` 打出 `游戏层 1:1`。

## 4. g-ctx2d（GT-C4~C8；A2.6）

画布 6×8 = 48 格，每格 60×60 逻辑像素，一格一个用例。格子顺序、内容**写死**，新增用例只往后加，不插队（否则所有格子的基线一起失效）。

```js
var T = require('_lib/t.js');
var c = wx.createCanvas(); c.width = 360; c.height = 480;
var ctx = c.getContext('2d');
ctx.fillStyle = '#ffffff'; ctx.fillRect(0, 0, 360, 480);
var cells = [
  function (g) { g.fillStyle = '#e33'; g.fillRect(10, 10, 40, 40); },                                   // 0 fillRect
  function (g) { g.strokeStyle = '#33e'; g.lineWidth = 4; g.strokeRect(10, 10, 40, 40); },               // 1 strokeRect
  function (g) { var l = g.createLinearGradient(0, 0, 60, 0); l.addColorStop(0, '#f00'); l.addColorStop(1, '#00f'); g.fillStyle = l; g.fillRect(5, 5, 50, 50); }, // 2 线性渐变
  function (g) { var r = g.createRadialGradient(30, 30, 2, 30, 30, 28); r.addColorStop(0, '#ff0'); r.addColorStop(1, '#080'); g.fillStyle = r; g.fillRect(2, 2, 56, 56); }, // 3 径向渐变
  function (g) { g.shadowColor = 'rgba(0,0,0,0.6)'; g.shadowBlur = 6; g.shadowOffsetX = 4; g.shadowOffsetY = 4; g.fillStyle = '#39f'; g.fillRect(10, 10, 34, 34); }, // 4 阴影
  function (g) { g.beginPath(); g.arc(30, 30, 22, 0, Math.PI * 1.5); g.lineWidth = 6; g.lineCap = 'round'; g.strokeStyle = '#a0a'; g.stroke(); }, // 5 圆弧 + round cap

  function (g) { g.translate(30, 30); g.rotate(Math.PI / 6); g.fillStyle = '#f80'; g.fillRect(-15, -15, 30, 30); },       // 8 变换
  function (g) { g.fillStyle = '#f00'; g.fillRect(10, 10, 30, 30); g.globalCompositeOperation = 'destination-out'; g.beginPath(); g.arc(35, 35, 15, 0, 7); g.fill(); }, // 9 合成模式
  function (g) { g.globalAlpha = 0.5; g.fillStyle = '#00f'; g.fillRect(5, 5, 35, 35); g.fillStyle = '#f00'; g.fillRect(20, 20, 35, 35); }, // 10 globalAlpha
  function (g) { g.beginPath(); g.moveTo(5, 55); g.bezierCurveTo(5, 5, 55, 55, 55, 5); g.lineWidth = 3; g.stroke(); }, // 11 贝塞尔
  function (g) { g.beginPath(); g.moveTo(30, 5); g.lineTo(55, 55); g.lineTo(5, 55); g.closePath(); g.lineJoin = 'miter'; g.lineWidth = 5; g.stroke(); }, // 12 lineJoin
  function (g) { var p = g.getImageData(0, 0, 4, 4); for (var i = 0; i < p.data.length; i += 4) { p.data[i] = 255; p.data[i + 3] = 128; } g.putImageData(p, 20, 20); }, // 13 像素读写（非预乘 128）

  // ……16~47 按 03 §2.2 的成员清单补齐，每格一个成员

cells.forEach(function (f, i) {
  ctx.save(); ctx.translate((i % 6) * 60, Math.floor(i / 6) * 60);
  ctx.beginPath(); ctx.rect(0, 0, 60, 60); ctx.clip();
  try { f(ctx); T.ok('cell' + i); } catch (e) { T.fail('cell' + i, e.message); }
  ctx.restore();
});
T.ready('g-ctx2d');
requestAnimationFrame(function () { T.done({ cells: cells.length }); });
```

判定：
- 日志里 `T:FAIL` 为 0。
- L3：整帧 md5 = 基线。
- L5：`game-compare.py --cells 6x8@60` 逐格算差异占比，每格 ≤ 该格阈值（05 §4.4），包围盒不得越出格子。超出时报告写明格号与 API 名。

## 5. g-touch-draw（GT-T1~T8；A3.1、A3.3）

```js
var T = require('_lib/t.js');
var c = wx.createCanvas(); var ctx = c.getContext('2d');
var k = c.width / wx.getSystemInfoSync().windowWidth;
var colors = ['#ff0000', '#00ff00', '#0000ff', '#ffff00', '#ff00ff', '#00ffff', '#ff8800', '#8800ff', '#008800', '#880000'];
var slot = {};   // identifier → 颜色槽，按首次出现顺序分配（不依赖 identifier 的取值规律）
var next = 0, pending = [];
function brief(e) {
  return { t: +e.timeStamp.toFixed(1),
           ids: e.touches.map(function (x) { return x.identifier; }),
           ch: e.changedTouches.map(function (x) { return [x.identifier, +x.clientX.toFixed(1), +x.clientY.toFixed(1)]; }),
           eq: e.changedTouches.every(function (x) { return x.clientX === x.pageX && x.clientX === x.screenX; }) };
}
['Start', 'Move', 'End', 'Cancel'].forEach(function (k2) {
  wx['onTouch' + k2](function (e) {
    T.ev('touch' + k2.toLowerCase(), brief(e));
    e.changedTouches.forEach(function (p) {
      if (!(p.identifier in slot)) slot[p.identifier] = next++ % 10;
      pending.push([slot[p.identifier], p.clientX, p.clientY]);
    });
  });
});
var n = 0;
function tick() {
  n++;
  // 同一帧到达的点在同一帧画出（A3.3）：本帧 rAF 消费 pending
  pending.forEach(function (p) { ctx.fillStyle = colors[p[0]]; ctx.fillRect(Math.round(p[1] * k) - 3, Math.round(p[2] * k) - 3, 6, 6); });
  if (pending.length) T.frame(n, { drawn: pending.length });
  pending = [];
  requestAnimationFrame(tick);
}
ctx.fillStyle = '#000'; ctx.fillRect(0, 0, c.width, c.height);
T.ready('g-touch-draw');
requestAnimationFrame(tick);
```

无头脚本（`--multitouch`，语法 `id:x,y@毫秒` 用 `;` 分隔，`id` 是宿主指针 id，`u` 前缀 = 抬起，`c` = 取消）：
```
--multitouch "7:100,200@0;7:110,200@16;9:300,400@32;u7:110,200@48;9:300,420@64;u9:300,420@80"
```
期望事件序列（`identifier` 记为 A、B，具体取值按取证规律）：
```
T:EV touchstart  {"ids":[A],   "ch":[[A,100,200]], "eq":true}
T:EV touchmove   {"ids":[A],   "ch":[[A,110,200]], ...}
T:EV touchstart  {"ids":[A,B], "ch":[[B,300,400]], ...}
T:EV touchend    {"ids":[B],   "ch":[[A,110,200]], ...}
T:EV touchmove   {"ids":[B],   "ch":[[B,300,420]], ...}
T:EV touchend    {"ids":[],    "ch":[[B,300,420]], ...}
```
`touches` 的顺序按按下先后（取证确认）。画面：(100,200)、(110,200) 两个红点，(300,400)、(300,420) 两个绿点。

## 6. g-audio 与 g-webaudio-offline（GT-AU；A5.x）

素材**不入库二进制**：由 `tools/gen-game-assets.py` 生成并写 sha256 清单（08 §6）。
- `a440.wav`：440Hz 正弦，48kHz 单声道 16bit，1.000s，幅度 0.5。
- `click.wav`：1ms 满幅方波（延迟测量用）。
- `bgm.mp3` / `bgm.m4a` / `bgm.ogg`：同一段 10s 和弦（ffmpeg 从 wav 编出，参数写进脚本）。

`g-audio/game.js`（真机手测 + 并发）：
```js
var T = require('_lib/t.js');
var bgm = wx.createInnerAudioContext(); bgm.src = 'assets/bgm.mp3'; bgm.loop = true; bgm.volume = 0.4;
['Canplay', 'Play', 'Pause', 'Stop', 'Ended', 'Error', 'Waiting', 'Seeking', 'Seeked'].forEach(function (e) {
  bgm['on' + e](function (r) { T.ev('bgm.' + e, r || {}); });
});
bgm.play();
var pool = [];
for (var i = 0; i < 32; i++) { var a = wx.createInnerAudioContext(); a.src = 'assets/click.wav'; pool.push(a); }
var idx = 0;
wx.onTouchStart(function () { pool[idx++ % 32].play(); });     // 每点一次一个音效
wx.onAudioInterruptionBegin(function () { T.ev('interruptBegin', {}); });
wx.onAudioInterruptionEnd(function () { T.ev('interruptEnd', {}); });
wx.onHide(function () { T.ev('hide', { bgmPaused: bgm.paused }); });
wx.onShow(function () { T.ev('show', { bgmPaused: bgm.paused }); });
T.ready('g-audio');
```

`g-webaudio-offline/game.js`（L5 音频对拍，无头 `MINI_AUDIO_OFFLINE=1`）：
```js
var T = require('_lib/t.js');
var ac = wx.createWebAudioContext();
var sr = ac.sampleRate;                        // 离线模式固定 48000
var buf = ac.createBuffer(1, sr, sr);
var d = buf.getChannelData(0);
for (var i = 0; i < d.length; i++) d[i] = Math.sin(2 * Math.PI * 440 * i / sr) * 0.5;
var src = ac.createBufferSource(); src.buffer = buf;
var g = ac.createGain(); g.gain.setValueAtTime(0, 0); g.gain.linearRampToValueAtTime(1, 0.5);
var bq = ac.createBiquadFilter(); bq.type = 'lowpass'; bq.frequency.value = 1000;
src.connect(g); g.connect(bq); bq.connect(ac.destination);
src.start(0.1);
T.ready('g-webaudio-offline');
// 离线模式下引擎把 destination 的 2s 输出写到 target/_game_audio/out.f32（小端 f32），由脚本与 Chrome OfflineAudioContext 同图比较
```
期望：0~0.1s 全零（`start(0.1)`）；0.1~0.5s 振幅线性上升；与 Chrome 同图逐样本最大误差 ≤ 阈值（首次实测 ×1.5，写进文档）。

## 8. g-lifecycle、g-landscape、g-worker、g-overlays、g-ads、g-net-fs

这几个夹具的结构是一样的：注册监听、执行动作、对每条检查打一行 `T:OK` / `T:FAIL` 或 `T:EV`。下面只列出必须覆盖的检查项，源码按同一种写法补齐（每个 ≤ 150 行）。

| 夹具 | 检查项（日志名） | 期望 |
|---|---|---|
| g-lifecycle | `launch`（打印 `getLaunchOptionsSync()`）、`show`、`hide`、`enter`（`getEnterOptionsSync()`） | LC1~LC3；冷启动是否触发 `show` 按取证 |
| g-landscape | 四角各画一个 20×20 的色块（左上红、右上绿、左下蓝、右下黄）；`onTouchStart` 在触点画白点并打印坐标；`onWindowResize` 与 `onDeviceOrientationChange` 打印 | O1：`windowWidth > windowHeight`；O2：点四角色块中心，打印坐标落在色块内 |
| g-worker | 主线程每帧打印 `dt`；worker 收到 `{cmd:'spin', ms:2000}` 后忙算 2s；`{cmd:'echo', buf}` 原样回传 16MB；`transfer` 后打印源 `byteLength` | W1：spin 期间主线程 `dt` 峰值与之前相同（±2ms，无头墙钟）；W2 |
